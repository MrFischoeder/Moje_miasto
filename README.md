# Moje miasto

Gra z otwartym światem w prawdziwych miastach (Warszawa, Londyn), w wektorowym stylu terminala CRT.

- `legacy/` – pierwotny prototyp „Miasto i metro FPP” (jeden plik HTML, three.js r128). Punkt odniesienia przy przenoszeniu.
- `data/` – dane metra (`cities.json`) i skrypt, który je zbudował (`prep.py`, źródła w `raw/`).
- `docs/PROMPT_CLAUDE_CODE.md` – założenia projektu i plan etapów.
